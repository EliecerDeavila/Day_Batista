# Day Diana Batista — Portafolio Profesional HSEQ

Sitio web personal de **Day Diana Batista**, Inspectora HSEQ (Seguridad, Salud en el Trabajo y Ambiente).

Construido con [Astro](https://astro.build) + [Tailwind CSS](https://tailwindcss.com) v4.

## Stack

- **Framework:** Astro 5
- **CSS:** Tailwind CSS v4 + CSS personalizado (animaciones, efectos 3D)
- **Fuentes:** Archivo Black, Poppins, Inter (Google Fonts)
- **Despliegue:** Netlify

## Scripts

```bash
npm run dev      # Iniciar servidor de desarrollo
npm run build    # Construir sitio estático
npm run preview  # Vista previa de la build
```

## Estructura

```
src/
├── components/   # Componentes Astro (Header, Hero, Skills, etc.)
├── layouts/      # Layout principal
├── pages/        # Rutas (index, 404)
├── scripts/      # JS cliente (animaciones, contadores, nav)
└── styles/       # global.css (Tailwind + design system)
public/
├── favicon.svg
└── img/          # Imágenes estáticas (foto de perfil)
```
